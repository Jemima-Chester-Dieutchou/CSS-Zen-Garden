
# CSS Zen Garden – Autumn Design

## About the Project

This project is part of a CSS Zen Garden assignment.
The goal is to improve the visual appearance of an existing HTML page using CSS only, without modifying the HTML structure.

The design is inspired by autumn, using warm and natural colors.

## Technologies

- HTML5 (provided structure)
- CSS3
- Git and GitHub
- Visual Studio Code

## Design Concept

The visual design uses an autumn-inspired color palette:

- Cream: `#F7F0E5`
- Terracotta: `#B95735`
- Dark brown: `#302722`
- Forest green: `#304B3D`
- Mustard yellow: `#D9B65D`

The objective is to create a clear, attractive and responsive layout.

## Project Structure

- `index.html` – HTML page structure
- `style.css` – visual styling
- `README.md` – project documentation

## Development Steps

1. Set up the project locally.
2. Initialize a Git repository.
3. Create the first commit.
4. Connect the local repository to GitHub.
5. Push the project to GitHub.
6. Develop and improve the CSS design.
7. Test the layout and document the final result.

## How to View the Project

Open `index.html` in a web browser to view the page.
